## Tentang Saya

Saya Muhammad Yasir Assafa. Saat ini saya mengerjakan proyek robot berbasis ROS2 dengan algoritma SLAM, menggunakan Gazebo untuk simulasi dan RViz2 untuk visualisasi.

- Sedang dikerjakan: robot SLAM dengan ROS2, Gazebo, dan RViz2
- Sedang dipelajari: navigasi otonom dan pemetaan lingkungan
- Terbuka untuk diskusi dan kolaborasi di bidang robotika

## Proyek Saat Ini

**Robot SLAM berbasis ROS2**

Robot yang dapat memetakan lingkungan sekaligus menentukan posisinya sendiri (SLAM). Pengembangan dan pengujian dilakukan di simulasi sebelum dicoba pada robot nyata.

| Komponen | Fungsi |
|:---------|:-------|
| ROS2 | Framework utama robot |
| Gazebo | Simulasi robot dan lingkungan |
| RViz2 | Visualisasi peta, sensor, dan posisi robot |
| SLAM | Pemetaan dan lokalisasi secara bersamaan |
